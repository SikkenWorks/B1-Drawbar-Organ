# SikkenWorks B1 V5.8

Built from the supplied V5.7 project for the M-VAVE FM1. The release scripts compiled and linked the AC791N target twice. Both builds produced identical application, firmware package and embedded installer bytes.

## Playback changes

- Master gain and ramps are calculated in a 2 KiB scratch buffer. Steady volume uses a shorter conversion loop. Full volume skips gain multiplication. A second time-budget check now covers the conversion before the DMA copy starts.
- DMA ownership is checked every 16 stereo frames and at completion. An ownership change during one group is still possible. These checks bound the size of an interrupted write and do not establish target timing.
- The block counter and peak callback time now include dropped blocks and recovery handling. The input scan timer uses a repeating ten-tick counter.
- Encoder reads preserve the enclosing parameter-edit interrupt mask. New Project preserves the live DSP profile across engine reset.
- Identical live snapshots return before the codec is muted. Changed snapshots recheck silence and pending MIDI under the interrupt mask before stopping audio. A genuine flash write still pauses audio and primes the codec for 330 ms. A note arriving after the write begins can be affected.

## Physical acceptance still open

On the FM1, open SCL / SCALE, use SELECT to open AUDIO DIAG, and leave TEST TONE off while playing. Record PEAK and DMA MISSES before and after each workload. A 256-frame half-buffer at 44.1 kHz lasts 5.805 ms. The firmware checks a 5.500 ms hard budget before copying. Hardware interrupt latency also consumes time.

Exercise 12 simultaneous MIDI notes across the three registrations, repeated chord attacks, rapidly moving drawbars, ORGAN and SAW, B3 and ROCK, high rotary/scanner/delay/reverb settings, and note-off tails. Repeat after New Project, project recall and a cold boot. Include a real autosave between phrases. Monitor both stereo channels for clicks, repeated audio, lost notes and interrupted attacks. A live/studio qualification requires measured headroom, unchanged miss counts and a clean recording on the physical unit.
