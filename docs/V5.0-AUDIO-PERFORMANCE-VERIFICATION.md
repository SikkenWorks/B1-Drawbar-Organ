# B1 V5.0 Audio & OTA Verification

Date: 2026-11-02  |  Firmware ID: `FM-1_481026`

## Scope

Engine changes only in `firmware/b1_engine.c` versus B1 V4.9. The original `firmware/ota.c`, `firmware/b1_ota_target.c`, `firmware/usb.c`, `firmware/b1_main.c`, `firmware/b1_storage.c`, `firmware/b1_performance.c`, and `firmware/b1_ui.c` were compared byte-for-byte against the V4.9 full-source ZIP and are unchanged. Protected loader and 16-KiB boot-header bytes remain pinned to the preexisting BEETLE RC1.01 reference. This does **not** establish universal compatibility with other firmware packages.

## Native DSP optimization

- Lazy shared-tonewheel sampling across all 91 oscillators is retained. V5.0 adds an adaptive unique-wheel work-list to the transient mixer only when there are at least three voices, sufficient harmonic overlap (8 or more avoidable duplicate accesses), and no note finishes releasing within the current PCM block. A lower-overlap chord stays with the existing low-overhead lazy mixer.
- The non-dense mixer now caches 27 smoothed drawbar gains per 16-frame control tick, rather than repeatedly loading Q16 gains per harmonic for each voice.
- The Hammond percussion capacitor envelope retains identical decay using an exact fast range split instead of an integer divide in its normal 1–32767 range. The old formula is preserved for abnormal/test values.
- Registration-aware chord headroom and linked peak guards are unchanged, as are the entire FX chain, DMA-buffer layout and emergency fade policy.

## Hardware measurement

1. Install using only a verified rescue/backup route; B1 firmware releases are not a guarantee of hardware flash safety.
2. Open **SCL/SCALE → SELECT → AUDIO DIAG**. Note the DMA MISSES counter before playing.
3. Play three, six and twelve simultaneous notes (organ and rock modes, with effects enabled). Compare the counter after each test.
4. Read PEAK (microseconds) during the stress. DMA half is 256 frames × 1/44,100 s = 5805 µs; the firmware hard deadline is 132,000 timer ticks / 24 MHz = 5500 µs; the soft threshold is 4583 µs.
5. If the DMA MISSES counter increases, the crackle is consistent with missed realtime deadlines. If it does not, capture the signal and test against analog gain/clipping rather than automatically disabling oscillators.

The host benchmark has large run-to-run scheduling/clock variability and **is not a verified JieLi speedup figure**. This release does not claim that the physical FM1 no longer crackles. A physical A/B timing capture is needed.


All OTA tests simulate flash in host memory. They do not program a connected FM1.
