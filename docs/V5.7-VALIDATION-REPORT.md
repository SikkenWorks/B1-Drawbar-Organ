## Native software validation, 2026-11-26

Firmware SHA-256: `c7f000299967cdc32c9839f1e35f9b58397cc4b07ba6b76176faaeb528a5962b`

The following checks ran successfully with `python3 tests/test_v57_release.py`:

- Firmware package structure, installed product ID, SHA-256 and embedded installer consistency.
- Executable browser installer JavaScript syntax via `node --check`.
- Known flash IDs Puya `0x856014` and UCUN `0xB36014`; reject unknown JEDEC.
- DSP reference source SHA-256 identical to V5.2 for `b1_engine.c` and `b1_performance.c`.
- 320 native full DSP state/PCM cases and 1,500,000 fixed-point arithmetic checks.
- Static DMA-policy checks for 256-frame buffer, deadline guard and fades.
- Native OTA replay: B1 V5.7, BEETLE RC1.01, B1 V5.2 and ORIGINAL M-VAVE Open V15 eight-entry FWSC all passed in host simulation.
- Negative OTA replay: UCUN + full stock V15, unverified executable loaders, missing host success handshake, abort, erase failure, readback corruption, unknown V16 boot layout and invalid XIP all rejected/aborted without an OTA commit.

**Not proven:** physical FM1 boot, audible result, measured DMA deadline misses, real UCUN/Puya storage/USB behavior, physical firmware crossgrade or round-trip, V16 bootloader compatibility, or a general promise that any custom/stock firmware can always be installed. Do not expose an unvalidated full-flash route on V16/new UCUN variants. Legacy B1 V5.2 cannot be fixed in-place if its installed CHECK routine refuses updates; independent confirmed UBOOT/recovery is required.
