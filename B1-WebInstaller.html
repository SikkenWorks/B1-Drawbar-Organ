Storage and recovery details
B1 STORAGE POLICY: B1 V4.9 scans 0xE7000–0xEFFFF for two positively verified blank or B1-owned 4KiB sectors for 12 named persistent projects. Any unfamiliar, corrupt, or foreign content is NEVER erased. If two safe sectors cannot be found, saving remains locked. BEETLE projects (0x97000–0xDFFFF) and OTA staging (0xE0000–0xE4FFF) remain separate. Once the vendor loader takes over, it controls firmware writing. Back up all data before installing, because a failed firmware update may require independent hardware recovery.

Read firmware safety warnings
Important: Package integrity and identified FM1 hardware cannot guarantee safe flashing. This installer cannot recover a device with an inaccessible bootloader or USB interface. Universal firmware switching / UBOOT
If a source firmware does not implement the compatible two-stage USB-MIDI OTA protocol, STOP and inspect the log. For ANY different loader or boot-image layout, B1 requests entry to the independent FM1 UBOOT mode. After reconnecting, use the target firmware's own compatible updater. This button does NOT write or approve the target firmware. Exact loader support and successful recovery depend on that firmware. You can also hold OCT- while switching on the FM1 if B1 is not responding. Back up projects before using any updater.

B1 REC recovery (when supported): start the FM1 holding REC (minimal USB mode without audio), then connect using desktop Chrome or Edge. If MIDI is not listed in Windows, try OCT- held at power-on for the independent UBOOT path. Connect directly with a USB data cable and close DAWs and other MIDI applications. Do not unplug during installation.

Technical installation notes

READ-ONLY DEVICE CHECK only sends identity queries; it does not start any update or write to flash. The identification FM-1_900 is shared; a successful handshake alone does not prove loader compatibility. A reboot between CHECK and FLASH is expected. If it reconnects to the old version instead of the OTA loader, the log records it. Save the log if an update fails.

A successful USB transfer is not enough. This installer reports success only after the FM1 restarts and returns the exact expected firmware identity.
